Database reference · schema.prisma

The CloudAct database, end to end

One Postgres database, reached through Prisma from the auth-server (calculator-code-auth). It holds everything the app persists — accounts, matters, saved calculator runs, and the whole forms engine. There is no second store: matters and calculator data live side by side in the same tables.

MatterRecord

6 fields

One JSON document per (matter, dataType): the five-step section arrays (income, expenses, assets…), folders/files metadata, per-file form data, and the change log (matter_change_log) — a dated, append-only record of values amended through the Update Information agent. New kinds of per-matter data land here as a new dataType rather than a new table, so they need no migration.

  • idIntPK
  • matterIdInt→ MatterFK
  • dataTypeStringUK
  • dataJson
  • createdAtDateTime
  • updatedAtDateTime
unique (matterId, dataType)
