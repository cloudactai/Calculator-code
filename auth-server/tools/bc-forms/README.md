# BC forms pipeline

Regenerates the BC templates in `form-template-export/` from the government sources.
Everything here is a build tool — the repo ships only the produced `BC*_.pdf/.json`
plus `catalog.json`. Staging lives in the gitignored
`form-template-export/_incoming_bc/`.

Requires Python 3 with PyMuPDF (`fitz`), Node, and Google Chrome.

## 1. Fetch and verify sources (gates A, B)

```
python3 fetch_bc.py
```

Downloads every form in `bc_sources.py` into `_incoming_bc/`, verifies PDF magic,
page count, and that the form's own number/title appears in the text, then writes
`_incoming_bc/manifest.json` with sha256, byte size, page count and
`kind: acroform | xfa`.

## 2. Provincial Court (AcroForm)

```
python3 build_bc_provincial.py [--promote]
```

Deletes the widget layer to leave the government's printed background, converts each
widget rectangle to the overlay convention, then runs the geometry, signature and
overlap gates. `--promote` copies the results into `form-template-export/`.

## 3. Supreme Court (XFA)

The Supreme forms are XFA; pdf-lib cannot fill them and react-pdf shows Adobe's
"Please wait" placeholder. They are flattened headlessly — no Adobe:

```
cd xfa && python3 -m http.server 8899 &          # render.html loads pdf.js from here
node print_xfa.mjs ./sc_out BCSC_F8::srcs/BCSC_F8.pdf [...]
```

`render.html` loads the form with pdf.js `enableXfa`, which lays XFA out as positioned
DOM, and Chrome (driven over CDP so printing waits for the render) prints it to a
static Letter PDF with a real text layer. It also exports `<docId>.fields.json` — the
government's own field boxes read off the rendered DOM in PDF points, which is what the
overlays are built from.

```
python3 build_bc_supreme.py [--promote]
```

**Only forms whose blank layout is the filing document are built.** The `INTERVIEW` set
in `build_bc_supreme.py` lists the Adobe wizard forms whose filed output is generated by
script at Preview time; flattening those blank produces a questionnaire, not a court
form. Source those from BC Laws Appendix A instead — see BC_MIGRATION_PLAN.md STATUS.

## 4. Catalog

```
python3 merge_catalog.py
npm run forms:validate-export
```

Rewrites the BC block of `catalog.json` (sortOrder from 101, ON's 1–45 untouched) and
regenerates `audit.json`.

## Overlay convention

`field.x` = box left in points, `field.y` = box top in points (y down), `width`/`height`
= points × 1.5. `FillPdf.savePdf` stamps `y = pageH − field.y − height/1.5`. Verified
against the Ontario templates (`Form8A` still carries its native widgets, so its overlay
map can be diffed against them directly).
